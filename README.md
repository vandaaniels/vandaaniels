## Selected work

### Bosses of Mass Destruction - Bedrock Adaptation

A public Minecraft Bedrock adaptation focused on recreating complex boss encounters, progression, structures, items, attacks, animations, and effects from the original Java project as faithfully as Bedrock allows.

- Four major boss encounters with custom combat systems
- Boss-specific AI, attacks, projectiles, structures, progression, and rewards
- Script API integrated with native Bedrock JSON, animations, particles, and resource-pack content
- Multiplayer-compatible systems
- PBR / Vibrant Visuals support
- Ongoing iteration based on player feedback and bug reports
- 4,000+ public downloads

**Project:** https://www.curseforge.com/minecraft-bedrock/addons/bosses-of-mass-destruction-unofficial-port
